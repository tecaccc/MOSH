## 实现详情

### 标题栏同步触发按钮

背景：手动同步此前只能进「设置 → 同步 → 手动同步」点击，路径深；标题栏仅有
一个只读的同步状态点（8px 圆点，不可点击）。

- **设计**：把状态点升级为可点击按钮——图标即状态，不另设独立指示器，
  避免状态点 + 按钮双元素冗余：
  - 位置：最小化按钮左侧（与「会话历史」开关同排，同步按钮更靠左）；
  - 仅启用同步时展示（与原状态点一致；未配置/停用时隐藏，浏览器直开
    config 为 null 自然不渲染）；
  - 图标（rotate-cw 环形箭头）随 `sync://status` 的 phase 变化：
    `syncing`=强调色 + 旋转动画、`error`=红色、`idle`=常色；
  - 悬停 title：同步中 / 上次失败原因（提示点击重试）/ 立即同步（附上次
    成功时间，无则「立即同步」）；
  - 同步进行中或 store busy（保存配置等）时禁用防并发；disabled 元素仍
    匹配 `:hover`，CSS 压掉悬停背景但保留状态色（同步中持续旋转）。
- **并发安全**：`useSyncStore.syncNow` 入口不唯一（设置页/标题栏按钮/失败
  toast 重试），加忙检查（`busy || phase === "syncing"` 直接 return）防重入。
- **样式**：复用 `tb-btn` 基类（规格/悬停/暗色/焦点环与窗口按钮一致），
  `tb-sync` 修饰类承载指针光标、左右细分隔线与 phase 配色；`.tb-sync + .tb-chat`
  去相邻双分隔线。移除旧 `tb-sync-pulse` 圆点动画，新增 `tb-sync-spin`。
- 操作反馈不变：成功/失败均走全局 toast（`sync://status` 事件统一驱动）。

验证：`npm run check` + `npm run build` 全绿（Rust 侧未改动）。

### 同步删除复活修复（会话墓碑）

报错现象：一方删除某条记录（AI 会话、待办、日程等），点击同步后刚删的内容
又从同步里出来（会话复活）。

- **根因**（引擎层红测试定位，`engine.rs::deleted_records_and_sessions_stay_deleted_after_sync`）：
  - **AI 会话**：`delete_agent_session` 是硬删除（消息行直接 DELETE），而
    `agent_messages` 的合并是纯并集（`ON CONFLICT DO NOTHING`，append-only 无
    墓碑）——删除动作无法经消息传播。A 删会话后点同步：拉到 B 的旧 dump
    （仍含该会话全部消息）→ 并集把消息原样插回 → 会话在删除它的那台设备上
    当场复活；且 `delete_agent_session` 此前未 `mark_dirty`，删除也不触发防抖推。
  - **待办/日程**：走软删墓碑 + LWW，同场景测试验证无复活（用户报告中的提及
    为会话问题的泛化感知）。
- **修复**：会话墓碑（只增不删的集合并集，与消息并集同构，无冲突裁决问题）：
  - `storage.rs`：迁移 v6 新增 `agent_session_tombstones(session_id PK, deleted_at)`；
    `delete_agent_session` 删除消息同时记墓碑并置脏；新增
    `list_session_tombstones` / `session_tombstoned` / `apply_session_tombstones`
    （并集入库 + 清理本地残留消息，返回清理行数）。
  - `dump.rs`：`Dump` 新增 `deleted_sessions` 字段（`#[serde(default)]`：旧 v1
    dump 无此字段首见空集；旧客户端收到新 dump 忽略未知字段——双向兼容，
    协议版本保持 1）；capture 携带墓碑。
  - `merge.rs`：每个 dump 先落地墓碑（清理本地消息），再逐条消息入库前查
    `session_tombstoned` 过滤（与 dump 应用顺序无关）；清理行数计入
    `messages_applied`（删除也是需刷新 UI 的消息变更，驱动 `reloadAfterSync`）。
  - 会话 id 为每会话新生的 UUID（前端 `crypto.randomUUID()`），不会重用撞墓碑；
    同步设计文档 §3.3 已补充会话墓碑一节。
- 行为：A 删会话 → 同步推墓碑（密文）→ B 拉取后清理消息并记录墓碑 → 再推；
  反复同步不再复活，收敛为全网删除。Tauri 命令层零改动（`delete_agent_session`
  签名不变）。

验证：`cargo test -p mosh-core` 125 用例（新增 4：引擎双设备删除场景红转绿、
合并墓碑清理/过滤/幂等、dump 墓碑往返与 v1 旧格式兼容、storage 删会话记墓碑）+
`cargo clippy -p mosh-core` + `cargo check --target x86_64-pc-windows-gnu` 全绿。
