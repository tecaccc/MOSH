## 实现详情

### 一、AI 聊天助手支持上传图片

**交互**：输入区工具条新增「图片」按钮（文件选择，可多选）；支持直接 **Ctrl+V 粘贴**
截图、**拖拽**图片文件到输入区；附件以缩略图预览（可逐个移除）；发送后用户气泡内
展示图片网格；历史会话回看图片仍在。空文本 + 图片可直接发送。

**前端压缩**（新增 `src/lib/image.ts`，控制落库/同步体积）：

- 解码后画布重绘：长边 ≤1600px 等比缩小、透明域填白、JPEG 重编码（GIF 取首帧）；
- 逐级降质量（0.9/0.75/0.6）再逐级降尺寸（×0.8，下限 480px）直到 ≤1.5MB；
- 单条消息 ≤4 张（与后端校验一致），超限/解码失败 toast 提示。

**传输与协议**：

- `agent_send` 新增 `images` 参数（data URL 数组；后端兜底校验：≤4 张、`data:image/`
  前缀、单张 ≤2.5MB；空文本 + 有图允许发送）。
- `ChatMessage` 新增 `images` 字段（不进默认序列化）；带图 user 消息经
  `to_request_value()` 组装为 OpenAI vision content 数组
  （`[{type:"text"},{type:"image_url"}]`），**无图消息线格式与旧版逐字节一致**
  （非 vision 供应商零影响）。
- LLM 上下文重建：历史 user 行带图回放，但**仅最近 3 条带图消息的图片进上下文**
  （防多轮后图片 token/费用膨胀；UI 回看不受限仍显示全部图片）。

**存储与同步**：

- `agent_messages` 表 v7 迁移：`ALTER TABLE ADD COLUMN images TEXT`（JSON 数组；
  NULL/损坏 JSON 读回空数组，旧库升级无损）。
- 图片随 `AgentMessage` 行 serde 携带 → 同步 dump/merge/幂等重放自然携带
  （旧版本读新 dump 忽略未知字段；新版本读旧 dump `serde(default)` 回空，
  已补 `docs/sync-design.md` 注记）。

### 二、发送后回复延迟（要等好一会）

**根因**：`agent_send` 在驱动 LLM 前，对**每台启用的 MCP 服务器**同步串行执行
`initialize` + `tools/list`（各 10s 超时），且**每条消息都重新走网络**——慢或不可达
的 MCP 服务器直接拖住 LLM 首包，这正是「发过去要等好一会」的主因。

**修复**（src-tauri 新增 `McpToolCache` 进程内缓存，server id → 工具列表）：

- **启动预热**：应用启动即后台拉取全部启用服务器的工具；
- **配置变更即刷新**：保存/启用服务器后台刷新；删除/停用作废缓存；同步落地设置
  变更（他机改了 MCP 配置）后也刷新；
- **发送路径只读缓存，绝不等待网络**：命中即用；过期（TTL 10 分钟）后台续期期间
  继续用旧值；冷缓存缺失时本轮跳过该服务器工具、后台拉取，下一轮自然可用；
- 顺带清掉 4 个存量 clippy 警告，恢复 `-D warnings` 质量门。

**主观等待优化**：首包前（流式中但尚无文本气泡）显示三点呼吸动画「思考中」指示。

### 三、AI 会话历史去持久化（内存态）

**用户决策**：聊天历史落库价值有限（隐私敏感、体积随使用无限增长、跨设备同步意义
不大），去掉持久化，全部存进程内存，重启即清空；后续有更好方案再上。

**mosh-core**：

- 新增 `MemoryAgentLog`（`HashMap<session_id, Vec<AgentMessage>>` + 内存墓碑集合）：
  append（墓碑拒写，防在途轮次滞后写入复活已删会话）/ list / list_sessions
  （首条 user 消息截 24 字符标题、最近活跃在前）/ delete_session；语义对齐旧 SQLite 实现。
- `runner` 消息读写改走 `MemoryAgentLog`（`db` 参数仅用于工具落库）；
  v7 的 images 列随消息同样进内存。
- 迁移 v8：`DROP TABLE agent_messages` + `agent_session_tombstones`（存量聊天
  记录清除，即用户诉求的「释放存储」）；`upgrades_v3` 测试同步改写。

**同步协议（版本仍为 1，双向兼容）**：

- dump 的 `agent_messages`/`deleted_sessions` 字段**保留但恒为空**：旧版本（≤0.5.3）
  读新 dump 需要键存在，否则整包解析失败跳过，会殃及 records/settings 同步；
  类型改 `Vec<Value>` 宽容解析旧 dump 里任意形态。
- merge 不再合并消息/墓碑；`MergeStats.messages_applied` 删除（SyncUi/前端同步删）。

**src-tauri / 前端**：

- `agent_send` 注入 `State<MemoryAgentLog>`；三个会话命令（list/messages/delete）
  改读内存；`reloadAfterSync` 及 `sync://status` 的消息门控删除。
- 会话侧栏保留（运行期多会话切换）：标签改「会话（重启清空）」，hover 提示内存态。

### 验证（历史去持久化）

  3 项 + 旧 dump 兼容解析 2 项）；clippy `-D warnings` 全绿；`tsc`/`build` 通过。
