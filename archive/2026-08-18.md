## 实现详情

### Toast 通知位置改回居中

- `.toast-layer` 从 `right: 16px` + `translateX(-50%)` 改为 `left: 0; right: 0; justify-content: center`，卡片从顶部居中向下弹出（与此前设置页本地 toast 一致）。

### MCP 工具展开列表
- 后端 `mcp_list_tools` 命令从只返回工具名（`Vec<String>`）改为返回完整 `McpToolDetail`（name / description / inputSchema），前端渲染为展开列表：
  - 每个工具一行卡片（surface-1 背景），显示工具名（等宽字体）
  - 工具用途描述（小字灰色）
  - 参数概览（等宽字体灰色，如 `query_string*(string)、location*(geo_object)、limit*(number) *`，必填项标 `*`）
- `AgentToolsSettings` 中 `formatToolParams()` 将 JSON Schema properties 展平为可读的「名称*(类型)」概览字符串。

### 顺带修复：`interface Record` 遮蔽内置 `Record<K,V>` 工具类型
- `types.ts` 中的 `interface Record`（原对齐 Rust `Record` struct）遮蔽了 TS 内置 `Record` 泛型，导致所有使用 `Record<string, unknown>` 的地方（包括 `McpToolDetail.input_schema`）报 TS2315。
- 重命名为 `RecordData`；全局 11 处引用更新为 `RecordData as RecordT` 或直接 `RecordData`。

验证：`tsc` + `vite build` + `cargo test`（110 用例）全绿。
