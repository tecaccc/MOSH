# PRD — 多设备同步 v1

> 任务：`08-18-sync-v1`。设计共识全文见 `docs/sync-design.md`（2026-08-18 grilling 会话固化）。

## 背景与动机

MOSH 本地优先，数据在本机 SQLite。用户家 / 公司两处交替使用，数据割裂。
需要正式的多设备同步能力，未来扩展至手机（v2）。

## 用户已裁决的边界

1. **传输 = S3 兼容对象存储**，主用腾讯云 COS，配置页通用（endpoint/region/bucket/AK/SK）。
2. **端到端加密**：APP 生成 32 字节随机密钥，文本串导出 / 粘贴导入。云端只见密文。
   密钥丢失 = 云端不可恢复（本地数据完好，可重新初始化覆盖）。
3. **同步范围 = 全部**（records + settings + agent_messages）。
   唯一例外：同步模块自身配置（COS 凭证 + 密钥），逻辑上不可能通过同步到达。
4. **合并 = LWW 静默**（updated_at 新者赢，revision tie-break），无冲突 UI。
   agent_messages 按 id 并集。墓碑永久保留，v1 无 GC。
5. **触发 = 事件驱动，无轮询**：启动拉 + 手动拉；变更后防抖 5s 推 + 退出兜底推。
6. **默认关闭、可选开启**（守住 README 本地优先承诺）。

## v1 验收标准

- [ ] 设置页「同步」卡片：S3 兼容配置（endpoint/region/bucket/AK/SK）+ 密钥生成/导出/导入
      + 启用开关（默认关）+「立即同步」+ 上次成功时间。
- [ ] 首次启用：生成 device-id（UUID）与 32 字节密钥，导出串可粘贴到第二台设备导入成功。
- [ ] 同步流程：拉所有设备 dump → 解密 → LWW 合并 → 写本地 → 推自己 dump（加密 gzip）。
- [ ] 云端对象内容为密文（人工抽查 COS 控制台确认不可读）。
- [ ] 变更后 5s 自动推（防抖）；APP 退出时兜底推一发；启动时自动拉。
- [ ] 标题栏状态点：同步中 / 已同步 / 错误（点开详情）；空闲时零网络请求。
- [ ] 端到端验收：设备 A 改待办 → 5s 后 COS 有新密文 → 设备 B 启动 → 待办可见。
- [ ] 软删在设备 B 同步后仍为删除状态（墓碑传播）。
- [ ] mosh-core 单元测试：LWW 合并（含 updated_at 相同走 revision）、
      agent_messages 并集、settings 覆盖、加解密 roundtrip。

## 非目标（v1 不做）

- 手机端（v2：Tauri 2 mobile + 二维码传钥）
- 记录级增量 / 秒级推送（v3：协议 version 字段已预留）
- 冲突解决 UI、同步历史页、墓碑 GC、双向实时
